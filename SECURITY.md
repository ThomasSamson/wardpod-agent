# Sécurité

Pour signaler une faille de l'agent, de son chart ou de son image, écrivez à **contact@wardpod.com** (voir aussi [security.txt](https://wardpod.com/.well-known/security.txt)), en français ou en anglais, plutôt que d'ouvrir une issue publique. Décrivez la version touchée, l'effet et, si possible, un moyen de le reproduire.

Le correctif part dans une nouvelle version de l'agent. Seule la dernière version est maintenue.
